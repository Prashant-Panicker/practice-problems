ONE-WEEK INTERVIEW PREP

SDE Interview Problem Set

A deliberately narrow set of problems for improving interview readiness in one week. Do not memorize solutions. For every problem, identify the pattern, explain the brute-force idea, derive the better approach, state time/space complexity, code it, and test edge cases.
